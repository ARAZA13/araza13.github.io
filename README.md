# Ahmed Raza — Personal Website

Modern dark-themed personal site for **Ahmed Raza** (Economist · Data Scientist · Policy Researcher).

## Features

- Dark modern design with teal accents
- Fully responsive
- Single-page with smooth scrolling navigation
- Clean typography (Instrument Serif + Inter)
- All original content reorganized for better flow

## Local preview

Just open `index.html` in a browser, or use any static server:

```bash
npx serve .
# or
python -m http.server 8000
```

## Deploy to GitHub Pages

1. Create a new repository (e.g. `yourusername.github.io` or `ahmed-raza-site`)
2. Push the contents of this folder to the `main` branch
3. In repo Settings → Pages → Source: Deploy from branch `main` / root
4. Your site will be live at `https://yourusername.github.io/` (or the project URL)

## Customization

- Replace `assets/img/headshot.png` with your preferred photo
- Edit content directly in `index.html`
- Colors and spacing live in the CSS variables at the top of `styles.css`
